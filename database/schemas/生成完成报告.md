所有生成的schema文件均包含以下内容:

### 1. 头部注释
```sql

-- API接口: table_name
-- API字段数: N
```

### 2. 表名中文注释
```sql
COMMENT ON TABLE table_name IS '中文表名';
```

- 字段名称

- PRIMARY KEY标记

### 4. 更新时间字段
每个表都包含 `updated_at TIMESTAMP DEFAULT NOW()` 字段

### 5. 主键定义
- 单字段主键: 直接在字段定义中标注 `PRIMARY KEY`
- 复合主键: 使用 `ALTER TABLE ADD PRIMARY KEY` 语句

### 6. 字段中文注释
```sql
COMMENT ON COLUMN table_name.field_name IS '字段中文说明';
```

### 7. 索引定义
所有常用查询字段均创建索引

## SQL类型推断规则

根据txt文件中的字段类型智能推断SQL类型:

### VARCHAR类型
- **代码类字段** (code, 代码): VARCHAR(20)
- **名称类字段** (name, 名称): VARCHAR(100)
- **状态类字段** (status, 状态): VARCHAR(20)
- **类型类字段** (type, 类型): VARCHAR(20)
- **市场/交易所**: VARCHAR(20)
- **行业**: VARCHAR(50)
- **原因描述**: VARCHAR(500)
- **进度**: VARCHAR(20)
- **默认字符串**: VARCHAR(100)

### DATE类型
- 字段名包含 `_date` 或 `date`
- 字段描述包含 "日期"

### REAL类型
- txt中类型为 `float` 的字段（金额、比率等）

### INTEGER类型
- txt中类型为 `float` 但字段名包含 `num`、`count` 或描述包含"数量"
