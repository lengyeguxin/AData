## Schema文件特性

所有生成的schema文件均包含以下内容:

### 1. 表名中文注释
```sql
COMMENT ON TABLE table_name IS '中文表名';
```

### 2. 字段中文注释
```sql
COMMENT ON COLUMN table_name.field_name IS '字段中文说明';
```

### 3. 更新时间字段
每个表都包含 `updated_at TIMESTAMP DEFAULT NOW()` 字段,用于记录数据更新时间。

### 4. 主键定义
- 单字段主键: 直接在字段定义中标注 `PRIMARY KEY`
- 复合主键: 使用 `ALTER TABLE ADD PRIMARY KEY` 语句

### 5. 索引定义
所有常用查询字段均创建索引,使用 `CREATE INDEX IF NOT EXISTS` 语句。

## 使用说明

### 加载schema文件到数据库
可以使用以下命令加载单个schema文件:
```bash
duckdb database/adata.db < database/schemas_new/table_name_schema.sql
```

### 批量加载所有schema文件
```bash
for file in database/schemas_new/*.sql; do
    duckdb database/adata.db < "$file"
done
```
