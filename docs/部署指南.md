## 常见问题

### Q1: 如何判断是否需要重建数据库？
**答案**：运行字段数检查脚本，如不匹配则重建。

### Q2: 数据拉取失败怎么办？
**答案**：
1. 检查游标状态（是否为running）
2. 检查前置表依赖（是否完成）
3. 检查API积分余额（是否充足）

### Q3: 如何清理重复拉取？
**答案**：使用游标管理器重置游标：
```bash
cd code/backend
python3 -c "
from src.core.global_cursor_manager import GlobalCursorManager

cursor_manager = GlobalCursorManager('../../database/adata.db', 'config')
cursor_manager.reset_cursor('stock_daily')
print('✅ stock_daily游标已重置')
"
```
