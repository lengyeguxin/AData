## 2. 部署方式

### 2.1 本地部署

适用于开发和测试环境。

#### 2.1.1 克隆代码

```bash
# 克隆项目
git clone <repository-url>
cd AData
```

#### 2.1.2 配置环境

```bash
# 创建虚拟环境（推荐）
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 或者分别安装
pip install duckdb pyyaml structlog apscheduler requests
pip install streamlit plotly pandas
```

#### 2.1.3 配置Tushare Token

```bash
# 复制配置文件
cp code/backend/config/config.yaml.example code/backend/config/config.yaml

# 编辑配置文件，填入Token
vim code/backend/config/config.yaml
```

```yaml
# 修改为你的Token
tushare:
  token: 你的实际token
```

#### 2.1.4 初始化数据库

```bash
# 初始化数据库
python3 code/backend/init_db.py
```

#### 2.1.5 启动服务

**启动后端**：

```bash
# 完整启动（数据拉取+定时任务）
python3 code/backend/main.py

# 或使用nohup后台运行
nohup python3 code/backend/main.py > logs/backend.log 2>&1 &
```

**启动前端**：

```bash
# 在另一个终端启动Dashboard
python3 code/frontend/run_dashboard.py

# 或使用nohup后台运行
nohup python3 code/frontend/run_dashboard.py > logs/dashboard.log 2>&1 &
```

### 2.2 Docker部署

适用于生产环境，提供更好的隔离性和可移植性。

#### 2.2.1 创建Dockerfile

**Dockerfile.backend**：

```dockerfile
FROM python:3.10-slim

WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    gcc \
    && rm -rf /var/lib/apt/lists/*

# 复制代码
COPY code/backend /app/code/backend
COPY database /app/database
COPY code/backend/requirements.txt /app/

# 安装依赖
RUN pip install --no-cache-dir -r requirements.txt

# 创建日志目录
RUN mkdir -p /app/logs

# 暴露端口（如果需要）
EXPOSE 8501

# 启动命令
CMD ["python3", "code/backend/main.py"]
```

**Dockerfile.frontend**：

```dockerfile
FROM python:3.10-slim

WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    gcc \
    && rm -rf /var/lib/apt/lists/*

# 复制代码
COPY code/frontend /app/code/frontend

# 安装依赖
RUN pip install --no-cache-dir streamlit plotly pandas duckdb

# 创建日志目录
RUN mkdir -p /app/logs

# 暴露端口
EXPOSE 8501

# 启动命令
CMD ["streamlit", "run", "code/frontend/dashboard/app.py", "--server.port=8501"]
```

#### 2.2.2 构建镜像

```bash
# 构建后端镜像
docker build -f Dockerfile.backend -t adata-backend:latest .

# 构建前端镜像
docker build -f Dockerfile.frontend -t adata-frontend:latest .
```

#### 2.2.3 创建docker-compose.yml

```yaml
version: '3.8'

services:
  backend:
    image: adata-backend:latest
    container_name: adata-backend
    volumes:
      - ./database:/app/database
      - ./logs:/app/logs
      - ./code/backend/config:/app/code/backend/config
    environment:
      - PYTHONUNBUFFERED=1
    restart: unless-stopped
    networks:
      - adata-network

  frontend:
    image: adata-frontend:latest
    container_name: adata-frontend
    volumes:
      - ./database:/app/database
      - ./logs:/app/logs
      - ./code/frontend/dashboard/config:/app/code/frontend/dashboard/config
    ports:
      - "8501:8501"
    environment:
      - PYTHONUNBUFFERED=1
    depends_on:
      - backend
    restart: unless-stopped
    networks:
      - adata-network

networks:
  adata-network:
    driver: bridge
```

#### 2.2.4 启动服务

```bash
# 启动所有服务
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down
```

适用于生产环境，提供稳定的服务。

#### 2.3.1 服务器准备

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装Python和pip
sudo apt install -y python3 python3-pip

# 安装git
sudo apt install -y git

# 安装nginx（可选，用于反向代理）
sudo apt install -y nginx
```

#### 2.3.2 部署应用

```bash
# 克隆代码
git clone <repository-url>
cd AData

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 配置文件
cp code/backend/config/config.yaml.example code/backend/config/config.yaml
vim code/backend/config/config.yaml  # 填入Token

# 初始化数据库
python3 code/backend/init_db.py
```

#### 2.3.3 配置Systemd服务

**后端服务**：

创建 `/etc/systemd/system/adata-backend.service`：

```ini
[Unit]
Description=AData Backend Service
After=network.target

[Service]
Type=simple
User=<your-username>
WorkingDirectory=/path/to/AData
Environment="PATH=/path/to/AData/venv/bin"
ExecStart=/path/to/AData/venv/bin/python3 /path/to/AData/code/backend/main.py
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
```

**前端服务**：

创建 `/etc/systemd/system/adata-frontend.service`：

```ini
[Unit]
Description=AData Frontend Service
After=network.target

[Service]
Type=simple
User=<your-username>
WorkingDirectory=/path/to/AData
Environment="PATH=/path/to/AData/venv/bin"
ExecStart=/path/to/AData/venv/bin/python3 /path/to/AData/code/frontend/run_dashboard.py
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
```

#### 2.3.4 启动服务

```bash
# 重新加载systemd配置
sudo systemctl daemon-reload

# 启动后端服务
sudo systemctl start adata-backend
sudo systemctl enable adata-backend  # 开机自启

# 启动前端服务
sudo systemctl start adata-frontend
sudo systemctl enable adata-frontend  # 开机自启

# 查看服务状态
sudo systemctl status adata-backend
sudo systemctl status adata-frontend

# 查看日志
sudo journalctl -u adata-backend -f
sudo journalctl -u adata-frontend -f
```

#### 2.3.5 配置Nginx反向代理（可选）

```nginx

    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://localhost:8501;
;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

```


## 3. 配置说明

### 3.1 主配置文件 (config.yaml)

```yaml
# 数据库配置
database:
  path: database/adata.db              # 数据库路径
  type: duckdb                        # 数据库类型

# Tushare API配置
tushare:
  token: YOUR_TOKEN_HERE               # 必填：API Token
  api_url: http://8.136.22.187:8010/ # API地址（可使用代理）
  rate_limit: 500                     # 每分钟请求限制
  random_sleep_min: 1                  # 随机休眠最小值（秒）
  random_sleep_max: 2                  # 随机休眠最大值（秒）

# 数据拉取配置
fetch:
  enabled: true                        # 是否启用数据拉取
  start_date: "20210101"             # 最早开始时间
  check: 60                           # 检测间隔（分钟）
  max_retries: 2                      # 失败重试次数
  retry_delay: 60                     # 重试间隔（秒）
  timeout: 60                         # API超时（秒）

# 快照配置
snapshot:
  enabled: true                       # 是否启用快照
  interval: 30                        # 快照间隔（分钟）
  locations:                          # 快照位置（支持多个）
    - database/adata_snapshot.db
    - /path/to/other/snapshot.db

# 调度器配置
scheduler:
  daily_update_time: "18:00"          # 日数据更新时间
  weekly_update_time: "19:00"         # 周数据更新时间
  monthly_update_time: "20:00"        # 月数据更新时间

# 日志配置
logging:
  level: INFO                         # 日志级别
  file: logs/adata.log                # 日志文件路径
  max_size: 10MB                     # 单个日志文件最大大小
  backup_count: 5                     # 保留的日志文件备份数量
```

## 5. 备份和恢复

### 5.1 数据库备份

```bash
# 创建备份目录
mkdir -p backups

# 备份数据库
cp database/adata.db backups/adata_$(date +%Y%m%d_%H%M%S).db

# 或使用rsync（增量备份）
rsync -av database/adata.db backups/adata.db
```

### 5.2 自动备份脚本

创建 `scripts/auto_backup.sh`：

```bash
#!/bin/bash

# 配置
BACKUP_DIR="/path/to/backups"
DB_PATH="/path/to/database/adata.db"
MAX_BACKUPS=10

# 创建备份
DATE=$(date +%Y%m%d_%H%M%S)
cp "$DB_PATH" "$BACKUP_DIR/adata_$DATE.db"

# 清理旧备份（保留最新的10个）
ls -t "$BACKUP_DIR"/adata_*.db | tail -n +$((MAX_BACKUPS + 1)) | xargs -r rm

echo "备份完成: adata_$DATE.db"
```

添加到crontab：

```bash
# 每天凌晨2点自动备份
0 2 * * * /path/to/scripts/auto_backup.sh >> /var/log/adata_backup.log 2>&1
```

### 5.3 数据库恢复

```bash
# 停止服务
sudo systemctl stop adata-backend
sudo systemctl stop adata-frontend

# 恢复数据库
cp backups/adata_20260417_120000.db database/adata.db

# 启动服务
sudo systemctl start adata-backend
sudo systemctl start adata-frontend
```

## 6. 故障排查

### 6.1 服务无法启动

**症状**：服务启动失败，提示找不到Python或模块

**解决**：
```bash
# 检查Python路径
which python3

# 检查虚拟环境
source venv/bin/activate

# 重新安装依赖
pip install -r requirements.txt

# 检查配置文件
ls -la code/backend/config/
```

### 6.2 API调用失败

**症状**：日志显示API请求失败

**解决**：
```bash
# 检查Token配置
grep token code/backend/config/config.yaml

# 测试API连接
curl -X POST http://8.136.22.187:8010/api/tushare/stock_basic \
  -H "Content-Type: application/json" \
  -d '{"token": "YOUR_TOKEN"}'

# 检查网络连接
ping 8.136.22.187

# 查看详细日志
tail -f logs/adata.log | grep ERROR
```

### 6.3 数据库损坏

**症状**：查询数据库时报错

**解决**：
```bash
# 检查数据库文件
ls -lh database/adata.db

# 尝试打开数据库
python3 -c "import duckdb; duckdb.connect('database/adata.db').execute('SELECT 1')"

# 如果损坏，从备份恢复
cp backups/adata_latest.db database/adata.db

# 或者重新初始化
python3 code/backend/init_db.py --force
```

### 6.4 Dashboard无法访问

**症状**：浏览器无法打开Dashboard

**解决**：
```bash
# 检查服务状态
sudo systemctl status adata-frontend

# 检查端口占用
netstat -tulpn | grep 8501

# 检查防火墙
sudo ufw status
sudo ufw allow 8501

# 检查日志
sudo journalctl -u adata-frontend -n 50
```

## 10. 常见问题

### Q1: 首次启动需要多长时间？

A: 首次启动需要拉取所有历史数据，根据网络和API限制，可能需要几小时到几天。建议使用`--fetch`模式先拉取数据，再启动完整服务。

### Q2: 如何只拉取特定表的数据？

A: 修改`table_config.yaml`，将不需要的表的`enabled`设为`false`，或者手动运行对应的collector。

### Q3: 可以同时运行多个Dashboard实例吗？

A: 可以。每个Dashboard实例使用不同的快照数据库，通过修改`dashboard_config.yaml`中的`port`和`database.path`实现。

### Q4: 如何减少API调用次数？

A: 1. 增加快照间隔；2. 减少拉取频率；3. 只拉取需要的数据表；4. 使用代理缓存。

### Q5: 数据库文件太大怎么办？

A: 1. 定期清理旧数据；2. 使用数据库压缩；3. 分库分表；4. 考虑使用分布式数据库。
