## 部署步骤（首次部署）

### Step 1: 初始化数据库Schema（必须）

```bash
cd /home/my/claude-project/AData

python3 -c "
import sys
from pathlib import Path
sys.path.insert(0, str(Path.cwd() / 'code' / 'backend'))

from src.core.database import Database

db = Database('database/adata.db')

# 执行所有Schema SQL文件
schema_dir = Path('database/schemas')
schema_files = sorted(schema_dir.glob('*_schema.sql'))

print('初始化数据库Schema...')
print('=' * 80)

for schema_file in schema_files:
    print(f'正在创建: {schema_file.name}')
    with open(schema_file, 'r', encoding='utf-8') as f:
        schema_sql = f.read()
    db.execute(schema_sql)

db.close()

print('=' * 80)
print('✅ Schema初始化完成（27表）')
"
```

**验证Schema完整性**：
```bash
python3 -c "
```

## 重要提示

1. **首次部署必须初始化Schema**
   - 当前数据库adata.db为空
   - 需执行Step 1初始化表结构

2. **数据拉取顺序很重要**
   - P0 → P1 → P2严格按顺序
   - 前置表必须先完成

3. **VIP积分消耗监控**
   - 建议先拉取少量数据测试
   - 确认积分充足后再全量拉取

4. **测试数据清理**
   - 当前数据库为空，无测试数据
   - 可直接开始真实数据拉取
